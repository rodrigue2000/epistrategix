# EpiStrategix - Plateforme de Conseil & Réservation

## 📋 Présentation
Plateforme de conseil avec réservation de créneaux et paiement en ligne via FedaPay.

## 🚀 Fonctionnalités
- ✅ Vitrine des services avec prix fixes ou libres
- ✅ Réservation de créneaux avec disponibilité en temps réel
- ✅ Paiement sécurisé via FedaPay (sandbox/live)
- ✅ Bibliothèque de contenus (gratuits/payants) avec Cloudinary
- ✅ Dashboard admin avec KPI et gestion complète

## 🛠️ Technologies
- **Backend** : Node.js + Express
- **Base de données** : Firebase Firestore
- **Authentification** : Firebase Auth
- **Paiement** : FedaPay
- **Stockage médias** : Cloudinary
- **Hébergement** : Render (backend) + Netlify/static (frontend)
